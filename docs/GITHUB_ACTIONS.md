# 🚀 Деплой на GitHub Actions 

**GitHub Actions** — це ідеальне місце для цього бота. Він запускатиметься повністю автоматично двічі на день, аналізуватиме нові вакансії, надсилатиме сповіщення і працюватиме **абсолютно безкоштовно**.

Більше того, кожного разу бот буде надійно оновлювати `data/state.json` прямо у репозиторії, тож дублів вакансій у вашому Telegram більше ніколи не буде.

Ось кроки, як налаштувати GitHub Actions всього за пару хвилин:

---

## Крок 1: Завантажте код на свій GitHub (якщо ще не зробили)

Спершу переконайтеся, що ваш код опубліковано в GitHub репозиторії. 

Щоб Actions запрацювали, ваш репозиторій може бути як **Публічним** (Public), так і **Приватним** (Private) — GitHub дає 2000 хвилин на місяць безкоштовно навіть для приватних репо. Оскільки цей скрипт відпрацьовує за 15 секунд, ви ніколи не перетнете цей ліміт.

---

## Крок 2: Додайте Secrets в GitHub

Ключі від Groq та Telegram-бота ні в якому разі не можна зберігати прямо в коді репозиторію. У GitHub є безпечне місце для них.

1. Зайдіть на головну сторінку вашого репозиторію.
2. Натисніть **Settings** (Налаштування) → **Secrets and variables** (зліва у меню) → **Actions**.
3. Натисніть зелену кнопку **New repository secret**.

Додайте по черзі три змінні:

| Name | Secret | Опис |
|------|--------|------|
| `GROQ_API_KEY` | `gsk_XXX...` | Ваш ключ з платформи [Groq Console](https://console.groq.com) |
| `TELEGRAM_BOT_TOKEN` | `1234:XXX...` | Токен бота, якого видав [@BotFather](https://t.me/BotFather) |
| `TELEGRAM_CHAT_ID` | `5421...` | Ваш ID, який видає [@userinfobot](https://t.me/userinfobot) |

---

## Крок 3: Перевірте перший запуск

Одразу після того, як ви завантажите сюди код і додасте Secrets, ви можете запустити перевірку власноруч:

1. Перейдіть на вкладку **Actions** в репозиторії GitHub.
2. Зліва натисніть на назву процесу: **Job Parser - Automated Checks**.
3. Справа знайдіть кнопку **Run workflow**, натисніть її і підтвердіть.

Через 10-20 секунд скрипт відпрацює. Якщо все іконки **Зелені (Success)**, ви невдовзі отримаєте сповіщення у вашому Telegram.

> **💡 Довідка:** Як тільки Action завершить роботу, він автоматично оновить і зробить коміт файла `data/state.json`.

---

## ⚙️ Налаштування розкладу (Розклад Cron)

За замовчуванням бот запускатиметься **двічі на день: о 6:00 та 18:00 UTC** (це 8:00 та 20:00 за європейським/норвезьким часом). 

Якщо ви бажаєте змінити час запуску екшену, відкрийте файл `.github/workflows/job-parser.yml` та змініть цей рядок:

```yaml
on:
  schedule:
    - cron: '0 6,18 * * *'  # 6:00 та 18:00 UTC
```

**Популярні приклади розкладів:**
- О 9 ранку кожного дня: `0 9 * * *`
- Кожні три години: `0 */3 * * *`
- Щобудня об 11:00: `0 11 * * 1-5`

*Використовуйте сайт [crontab.guru](https://crontab.guru/) для генерації свого розкладу.*

## 🐛 Вирішення проблем (Troubleshooting)

### 1. Червоний Хрест: "remote: Permission to ... denied to github-actions[bot]"
У старіших репозиторіях іноді GitHub Actions має доступ лише "на читання". 
**Рішення:** Це вже виправлено напряму в коді `job-parser.yml` блоком `permissions: contents: write`!

### 2. Помилка: "ModuleNotFoundError: No module named 'groq'"
**Рішення:** Ваш `requirements.txt` містить помилки або застарів. GitHub автоматично завантажує пакети тільки з цього файлу (зокрема `openai`, що сумісний з `groq`).

### 3. Помилка Telegram: "Unauthorized" або "Bad Request"
**Рішення:** Переконайтесь, що `TELEGRAM_BOT_TOKEN` правильний і бот створено через BotFather. Переконайтесь у вірному `TELEGRAM_CHAT_ID` і, що дуже важливо, що ви **написали "/start" або будь-яке повідомлення вашому боту** до того, як відправляти сповіщення. Бот не має права писати вам першим!
